# 🪶 Poemas de Natanael — Wiki

Bem-vindo à wiki oficial do projeto **Poemas de Natanael**!

Este é um site autoral de poesia desenvolvido com Vanilla JS, Vite, Firebase e GitHub Pages. Aqui você encontra toda a documentação técnica para entender, configurar e contribuir com o projeto.
