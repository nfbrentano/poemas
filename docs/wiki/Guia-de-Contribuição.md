# 🤝 Guia de Contribuição

Resumo rápido para contribuidores. Para o guia completo, veja [CONTRIBUTING.md](https://github.com/nfbrentano/poemas/blob/main/CONTRIBUTING.md).

## Fluxo Resumido

```
1. Fork o repositório
2. Clone: git clone https://github.com/SEU-USUARIO/poemas.git
3. Instale: npm install
4. Crie uma branch: git checkout -b feature/minha-contribuicao
5. Faça alterações
6. Teste: npm run test
7. Commit (veja convenção abaixo)
8. Push: git push origin feature/minha-contribuicao
9. Abra um Pull Request
```

## O que aceitar vs. não aceitar

| ✅ Aceito | ❌ Não aceito |
|----------|-------------|
| Correções de bugs | Conteúdo poético (poemas são autorais) |
| Melhorias de performance | Mudanças de framework (React, Vue, etc.) |
| Correções de acessibilidade | Dependências desnecessárias |
| Melhorias de SEO | Mudanças drásticas de design sem discussão prévia |
| Documentação | |
| Testes | |

## Stack

- **Vanilla JS** (ES Modules, sem framework)
- **Vanilla CSS** (sem pré-processadores)
- **Vite** (bundler)
- **Vitest** (testes)
